# MeMoDe

Çayan Kuzu'nun resmî ürün ve deneyim portföyü. Seçili web deneyimlerini ve mobil ürünleri amaç, kısa özet, teknoloji etiketleri ve ilgili bağlantılarla sunar; Creator bölümü üretici profilini portföyün içinde tutar.

Deneysel proje vitrini [fikkis](https://fikkis.vercel.app) ile animasyonlu bir portal üzerinden bağlıdır. MeMoDe, Fikkis'ten ayrı bir klasör ve ayrı bir private GitHub deposudur.

## Yerel geliştirme

```bash
npm install
npm run dev -- -p 3001
```

Fikkis portal hedefi `NEXT_PUBLIC_FIKKIS_URL` ile ayarlanır.

## Vercel

Bu depo Vercel'de bağımsız bir proje olarak ve kök dizinden (`.`) yayınlanır.
